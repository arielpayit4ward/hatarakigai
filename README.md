# Work Worth Doing

**A gentle hatarakigai companion from [Seeking Ikigai](https://www.seekingikigai.online).**

**Live app:** https://hatarakigai.lovable.app

Work Worth Doing is a free web companion to my essay [How To Find Work Worth Doing](https://www.seekingikigai.online/p/how-to-find-work-worth-doing). *Hatarakigai* is the Japanese idea of work that feels worth doing... not a grand single purpose, but work that brings together what you love, what you're good at, what you can be paid for and what the world needs.

I built it to help you move out of endless reflection and into small, real experiments.

## What's inside

- **The Threshold:** a welcome, Ken Mogi's five pillars of ikigai and an optional acrostic warm up.
- **Fourteen stones on a garden path,** in three phases:
  1. *The Foundation:* joys, labels and loves, values.
  2. *Designing the Work:* strengths, other people's views, the market, a smallest paid test, favourite problems and the SDGs.
  3. *Bringing It Together:* your real constraints, then choosing one pathway and one small experiment.
- **The Design Table:** your answers laid across the Work Worth Doing Venn diagram (see [Everyone Gets the Venn Diagram Wrong](https://www.seekingikigai.online/p/everyone-gets-the-venn-diagram-wrong)), with an optional "Give me an AI idea" spark.
- **The Compass Log:** note what you tried and whether it moved you toward or away from meaning.
- **One Sentence:** what makes work feel worth doing, for you, ready to share in the essay comments.

Each step is tagged *Reflect*, *Check* or *Test*, and you can walk them in any order. Stones simply turn from pencil to watercolour as you go. No streaks, points, badges or verdicts.

## Privacy

Your writing stays in your own browser (local storage). There are no accounts and no analytics. You can export to Markdown, print, back up, restore or clear everything at any time. The only thing ever sent to a server is the optional AI idea, which receives just a few randomly picked answers.

## Built with

TanStack Start, React, Tailwind CSS and [Lovable](https://lovable.dev). Changes made in Lovable sync to this repository automatically.

### Run it locally

You'll need Node.js (or Bun).

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```
